# 10. Glosario

| Término                         | Definición                                                                                                   |
|-----------------------------------|------------------------------------------------------------------------------------------------------------------|
| **ERP** (Enterprise Resource Planning) | Sistema de planificación de recursos empresariales que integra en una sola plataforma los procesos administrativos de una organización; en este proyecto, de un conjunto residencial. |
| **Conjunto Residencial**           | Edificación o conjunto de edificaciones sometidas al régimen de propiedad horizontal, administradas de forma conjunta. |
| **Propiedad Horizontal**           | Régimen jurídico que regula la propiedad compartida de bienes comunes en conjuntos residenciales o comerciales. |
| **Residente**                      | Persona que habita una unidad dentro del conjunto residencial, sea o no propietaria de la misma.                |
| **Propietario**                    | Persona titular del derecho de dominio sobre una unidad (apartamento) dentro del conjunto residencial.          |
| **PQRS**                           | Peticiones, Quejas, Reclamos y Solicitudes registradas por los residentes o propietarios ante la administración. |
| **Auxiliar Administrativo**        | Rol del sistema encargado de apoyar el registro y seguimiento de residentes, solicitudes y documentos.          |
| **Administrador del Conjunto**     | Rol del sistema con visibilidad y control total sobre la operación administrativa del conjunto residencial.     |
| **Personal de Mantenimiento**      | Rol del sistema encargado de ejecutar y actualizar las actividades de mantenimiento asignadas.                  |
| **Personal de Vigilancia**         | Rol del sistema con acceso restringido a la información permitida según sus funciones.                          |
| **Documento**                      | Archivo cargado en el sistema (acta, contrato o manual) clasificado con una categoría y una fecha.               |
| **Categoría de Documento**         | Clasificación asignada a un documento (por ejemplo: actas, contratos, manuales) que facilita su organización y búsqueda. |
| **Auditoría**                      | Registro histórico de las acciones realizadas por los usuarios sobre las entidades del sistema (quién, qué acción y cuándo). |
| **Mantenimiento Preventivo**       | Actividad de mantenimiento planificada con el fin de evitar fallos futuros en las instalaciones del conjunto.    |
| **Mantenimiento Correctivo**       | Actividad de mantenimiento realizada para solucionar un daño o falla ya presentada.                             |
| **Rol y Permisos**                 | Mecanismo mediante el cual cada usuario del sistema tiene acceso únicamente a las funciones correspondientes a su perfil. |
| **WPF (Windows Presentation Foundation)** | Framework de Microsoft utilizado para construir la interfaz gráfica de escritorio del ERP.               |
| **Entity Framework Core**          | ORM (Object-Relational Mapper) utilizado para el acceso a la base de datos desde la Capa de Acceso a Datos.      |
| **Indicador de Gestión**           | Métrica calculada por el sistema (por ejemplo, tiempo promedio de atención de una PQRS) que apoya la toma de decisiones administrativas. |
